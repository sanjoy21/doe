Emergency Skills API Instructions

Call: http://doe.emergencyskills.com/api/api.php
Method: POST
Returns: JSON
Possible Methods: doLogin getSchools downloadData

Method: doLogin

Arguments:
    username (string)
    password (string)

Returns:
    status: "error" or "success"
    userid: integer (if successful)
    attributes: array of values (if successful)
    error_message: string (if error)

Method: getSchools

Arguments:
    userid (integer)
    zipcode (string, optional)

Returns:
    status: "error" or "success"
    schools: array of values (if successful)
